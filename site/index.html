همگام‌سازی منابع

افزودن لینک اشتراک HTTPS و پیش‌نمایش کانال عمومی تلگرام؛ واردکردن لینک‌های جدید و حذف موارد تکراری با همگام‌سازی زمان‌بندی‌شده.

⤳

کتابخانهٔ کانفیگ‌ها

واردسازی لینک‌های VLESS، VMess، Trojan، Shadowsocks، Hysteria2، TUIC، AnyTLS و پراکسی‌های HTTP/SOCKS5 که قالبشان شناخته شود.

⇄

انتخاب مسیر خودکار

ساخت تنظیمات sing-box و گروه URL-test برای آزمودن مسیرها، همراه با تلاش مجدد اجرای موتور پس از خروج غیرمنتظره.

◈

رابط شبیه اپلیکیشن

داشبورد فارسی RTL، نوار ناوبری پایین موبایل، نمای اتصال، کتابخانهٔ نودها، منابع، مسیرها و عیب‌یابی؛ قابل نصب به‌شکل PWA برای پوستهٔ محلی.

⌁

آزمون انتهابه‌انتها

بررسی HTTP/HTTPS از داخل پراکسی، latency و سلامت مسیر؛ بازبودن پورت به‌تنهایی سالم محسوب نمی‌شود.

◉

حریم خصوصی محلی

API کنسول فقط روی loopback، توکن جلسه، CSP، عدم استفاده از CORS و ذخیرهٔ فایل کانفیگ با مجوز محدود سیستم‌عامل.

شروع کار

اتصال واقعی به موتور سازگار نیاز دارد

01نصب آلفا و sing-box

باینری آلفا را از انتشارها بگیر؛ موتور sing-box باید در PATH یا پوشهٔ `engines` در دسترس باشد.

02ورود کانفیگ یا منبع

یک اشتراک قابل دسترس یا لینک خام وارد کن، یا کانال عمومی را دنبال کن. اطلاعات ورود کانفیگ به API عمومی نمایش داده نمی‌شود.

03اتصال و تنظیم پراکسی

اتصال را دستی آغاز کن. اگر sing-box پیکربندی را تأیید کند، آلفا از SOCKS5 محلی روی 127.0.0.1:1088 استفاده می‌کند.

موتور خارجی

نودهای واردشده با موتور sing-box اجرا می‌شوند. آلفا در این نسخه خودش پروتکل TLS/VLESS را از صفر پیاده نکرده است.

موبایل native

رابط PWA جایگزین Android VpnService یا iOS NetworkExtension نیست؛ در این مرحله اتصال اپلیکیشن‌ها به پراکسی محلی هدف است.

سیاست امنیتی: کانفیگ عمومی را قابل‌اعتماد فرض نکن. اپراتور هر نود ممکن است مقصدهای ترافیک را ببیند. آلفا برای جلوگیری از افشای کلیدها URIهای کامل را در لیست API و گزارش عیب‌یابی نشان نمی‌دهد؛ بااین‌حال فایل‌های محلی را از دستگاه مشترک کپی نکن.
