> **نسخه: 0.4.1-alpha — آزمایشی.** واردسازی منابع و تولید تنظیمات sing-box اضافه شده، اما هنوز VPN بومی سراسری Android/iOS، ادغام پروتکل TheFeed از روی DNS، iodine یا Spoof Tunnel و آزمون میدانی روی شبکه‌های ایران تکمیل نشده‌اند.

آلفا یک برنامهٔ محلی برای جمع‌آوری کانفیگ‌های سازگار، دنبال‌کردن منابع عمومی قابل دسترس، آزمودن مسیرها و مدیریت اتصال از طریق موتورهای بیرونی است. هستهٔ اصلی آلفا خودش پروتکل‌های VLESS/VMess/Trojan را پیاده‌سازی نمی‌کند؛ برای اجرای آن نودها از sing-box استفاده می‌کند.

## قابلیت‌های نسخهٔ 0.4.1-alpha

- پنل فارسی RTL با ناوبری دسکتاپ و نوار پایین موبایل: نمای کلی، اتصال، کانفیگ‌ها، منابع، مسیرها و عیب‌یابی.
- واردسازی لینک‌های `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` / `hy2://`, `tuic://`, `anytls://`, `socks5://`, `socks://`, `http://` و `https://` که با parser سازگار باشند.
- واردسازی متن اشتراک Base64 در کنار چند لینک جداشده با خط جدید.
- فهرست محلی پایدار و deduplication بر اساس لینک؛ URIهای کامل حاوی رمز در API فهرست یا گزارش عیب‌یابی نمایش داده نمی‌شوند.
- افزودن منابع HTTPS و کانال‌های **عمومی** تلگرام مثل `@thefeedconfig`; همگام‌سازی هر ۱۵ دقیقه. در صورت شکست HTTPS مستقیم، تلاش دوم از پراکسی SOCKS5 محلی آلفا با مقصد IP عمومی اعتبارسنجی‌شده انجام می‌شود؛ بررسی عادی TLS حفظ می‌شود.
- تولید خودکار کانفیگ sing-box و گروه `urltest` برای آزمایش و انتخاب نودها؛ با خروج ناگهانی موتور، supervisor تلاش می‌کند آن را دوباره اجرا کند.
- CI هشت نمونهٔ پروتکل را با باینری رسمی sing-box نسخهٔ 1.14.2 و بررسی SHA-256 اعتبارسنجی می‌کند؛ این آزمون سازگاری فایل تنظیمات است و اثبات اتصال زنده به سرور واقعی نیست.
- مدیریت پراکسی SOCKS5 محلی روی `127.0.0.1:1088` و بررسی سلامت endpointهای محلی با آزمون واقعی HTTP/HTTPS.
- ذخیرهٔ catalog و کانفیگ فعال در پوشهٔ تنظیمات کاربر؛ فایل‌ها روی سیستم‌عامل با مجوز محدود نوشته می‌شوند.
- توکن جلسه، CSP، رد درخواست cross-origin، اندازهٔ محدود درخواست‌ها، بررسی DNS/redirect منبع و pin کردن HTTPS به IP عمومی؛ HTML دارای توکن در service worker cache نمی‌شود و listener فقط روی loopback است.

## شروع سریع — ویندوز

1. فایل Alpha را از صفحهٔ Releases دریافت و استخراج کن.
2. در اجرای اول `Start-Alpha.bat` یک `config.json` نمونه می‌سازد؛ آن را بررسی و سپس فایل اجرا را دوباره راه‌اندازی کن.
3. موتور `sing-box` را از [منبع رسمی](https://github.com/SagerNet/sing-box/releases) نصب کن و مطمئن شو دستور `sing-box` در `PATH` در دسترس است یا فایل را در پوشهٔ `engines` کنار آلفا قرار داده‌ای.
4. آلفا را اجرا کن و در کنسول «منابع» یا «کانفیگ‌ها» را باز کن؛ لینک‌های خودت را وارد کن.
5. دکمهٔ «اتصال هوشمند» پیکربندی را اعتبارسنجی می‌کند و سپس موتور را اجرا می‌کند. برنامه‌هایی که می‌خواهی از مسیر استفاده کنند باید به SOCKS5 محلی `127.0.0.1:1088` متصل شوند.

برای اجرا از سورس (Go 1.23+):

```bash
cp config.example.json config.json
go test -race ./...
go vet ./...
go run ./cmd/resilience engines
go run ./cmd/resilience ui --config config.json
```

## منابع و همگام‌سازی

- منبع HTTPS باید یک اشتراک متنی/ Base64 با لینک‌های قابل پشتیبانی برگرداند.
- برای تلگرام فقط پیش‌نمایش عمومی `t.me/s/<channel>` خوانده می‌شود؛ کانال خصوصی، لینک دعوت و محتوایی که از شبکهٔ فعلی قابل دسترسی نباشد پشتیبانی نمی‌شود.
- منابع نمونه در رابط: `@thefeedconfig` و `@networkti`. این‌ها نمونه‌های عمومی‌اند، نه تأیید امنیت/کیفیت یا تضمین دسترس‌پذیری.
- اضافه‌کردن منبع خودش به معنی اتصال به نودهایش نیست. برای جلوگیری از اجرای غافلگیرانهٔ کانفیگ ناشناس، اتصال باید با اقدام صریح کاربر آغاز شود.
- همهٔ منابع خودکار بی‌انتها نیستند: محدودیت عملیاتی فعلی ۱۰۰۰ منبع، ۵۰٬۰۰۰ نود ذخیره‌شده و ۸ مگابایت برای هر دریافت است.

## چه چیزی هنوز کامل نشده؟

- **Google search scraping/API:** فعال نیست؛ خزش نتایج جست‌وجو منبع پایدار و امن اشتراک نیست. در حال حاضر لینک مشخص HTTPS یا کانال عمومی لازم است.
- **TheFeed protocol:** این پروژه یک فید/پیام‌رسان مبتنی بر DNS هم دارد؛ خواندن کانال تلگرام @thefeedconfig با ادغام پروتکل DNS خود TheFeed متفاوت است. خود پروتکل TheFeed هنوز در آلفا ادغام نشده است.
- **iodine و Spoof Tunnel:** آداپتور TUN/IP اختصاصی، احراز هویت/امنیت و آزمون دوطرفه‌شان آماده نیست؛ آن‌ها به‌عنوان موتور آماده ادعا نمی‌شوند.
- **Diban / MasterHttpRelayVPN / Psiphon / Xray / Tor:** Alpha فقط در صورت ارائهٔ endpoint سازگار یا باینری/تنظیمات معتبر می‌تواند از آن‌ها استفاده کند. کلاینت‌های این پروژه‌ها داخل سورس یا باینری Alpha کپی نشده‌اند.
- **Android/iOS:** پوستهٔ PWA با VPN سیستمی تفاوت دارد. `VpnService` اندروید و `NetworkExtension` در iOS هنوز ساخته نشده‌اند.
- **آزمون میدانی:** این محیط به سرورهای واقعی کاربران دسترسی ندارد؛ اتصال شبکه‌ای واقعی، روش‌های ضدسانسور، سرعت و کارکرد زیر خاموشی سراسری هنوز تأیید نشده‌اند.

## امنیت و انتظارات

نود ناشناس قابل اعتماد فرض نمی‌شود. اپراتور نود ممکن است مقصدها و داده‌های رمزگذاری‌نشده را ببیند؛ TLS برنامه‌ها همچنان باید معتبر بماند. فایل catalog شامل URIهای کامل و credential نود است و باید از آن محافظت شود. از انتشار `catalog.json`، `sing-box.active.json` یا لینک‌های خصوصی خودداری کن.

**هیچ برنامه‌ای نمی‌تواند وقتی تمام مسیرهای خارجی قطع شده‌اند، فقط با نرم‌افزار اینترنت بین‌الملل تولید کند.** همگام‌سازی منابع هم به مسیری برای رسیدن به همان منبع نیاز دارد.

## تست و انتشار

```bash
gofmt -w ./cmd ./internal
go test -race ./...
go vet ./...
./scripts/build-release.sh
```

CI، ساخت باینری برای Windows/Linux/macOS و انتشار Pages در `.github/workflows/` قرار دارند. باینری‌ها cross-compile می‌شوند و باید روی دستگاه واقعی هر سیستم‌عامل آزمایش شوند؛ نسخهٔ فعلی امضای کد یا installer native ندارد.

## انتشار خودکار روی GitHub

برای انتشار از Windows پس از استخراج سورس، وارد GitHub CLI شو (`gh auth login`) و در PowerShell اجرا کن: `./Publish-Alpha-To-GitHub.ps1`. این اسکریپت فقط به `Ehsanamn1/alpha` انتشار می‌دهد، هویت حساب را بررسی می‌کند و از overwrite شاخه‌ای که فایل دارد جلوگیری می‌کند.
