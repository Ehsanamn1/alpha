# وضعیت ادغام موتورهای Alpha

| موتور/پروژه | وضعیت | روش فعلی/برنامه | محدودیت کلیدی |
|---|---|---|---|
| پراکسی SOCKS5 سفارشی | قابل استفاده در آلفا | اتصال از طریق آدرس loopback | باید از قبل end-to-end کار کند |
| Diban | قابل اتصال بیرونی | اگر پراکسی محلی Diban فعال است، معمولاً `127.0.0.1:1080` | نیازمند رله قابل دسترس؛ MITM/CA دیبان باید جداگانه بررسی شود |
| sing-box | آداپتور پروسه عمومی موجود است | اجرای باینری و فایل config که SOCKS inbound دارد | کانفیگ/سرور بر عهده کاربر؛ مستقیم بودن outbound، ضد فیلترینگ نیست |
| Xray-core | آداپتور پروسه عمومی موجود است | اجرای باینری و فایل config که SOCKS inbound دارد | کانفیگ/سرور بر عهده کاربر |
| Tor | پروفایل نمونه قابل اجراست | باینری Tor و SOCKS 9050؛ bridge/transports باید جداگانه تنظیم شوند | bridge در دسترس لازم است؛ دسترسی تضمین نمی‌شود |
| Psiphon | اتصال بیرونی | وصل‌کردن کلاینتی که پراکسی محلی ارائه می‌کند | کنترل مستقیم lifecycle به نوع کلاینت/نسخه وابسته است |
| MasterHttpRelayVPN / Zyrln / LTSC | در مرحله ممیزی | از طریق SOCKS محلی اگر پروژه چنین endpointی ارائه کند | کد آن‌ها در Alpha کپی نشده؛ مجوز و امنیت جداگانه باید ممیزی شود |
| Spoof Tunnel | پژوهشی، هنوز در روتر ادغام نشده | نیازمند طراحی لینک، لایه امن و آزمون دو گره مجاز | نسخه جدید یک UDP pipe ساده است؛ پیش‌نیازهای شبکه خاص دارد |
| iodine | پژوهشی، خارج از روتر SOCKS | تونل DNS نیازمند آداپتور IP/TUN یا یک پراکسی متناسب است | کم‌سرعت‌تر؛ DNS خارجی باید عبور کند؛ خود تونل رمزنگاری ذاتی ندارد |
| TheFeed | خارج از مسیر full-tunnel | برنامه اضطراری فید/پیام‌رسانی | اینترنت عمومی را برای همه اپ‌ها تونل نمی‌کند |
| Ceno | خارج از روتر | مرورگر اشتراک محتوا | دسترسی به محتوای ذخیره‌شده/قابل دریافت، نه اینترنت تضمینی در خاموشی کامل |
| GoodbyeDPI / zapret | ابزار سیستم‌عامل، خارج از SOCKS | فقط در یک ماژول پلتفرمی مستقل و آزمایش‌شده قابل بررسی است | مسیر فیزیکی اینترنت ایجاد نمی‌کند |

**قانون ادغام:** هر موتور باید کد، مجوز، ورودی/خروجی، مدیریت کلید، چرخه اجرای فرایند، telemetry و تست پذیرش خودش را داشته باشد. تنها آداپتورهای `external-socks5` و `managed-socks5` فعلاً قابل عبور از روتر اصلی Alpha هستند. انواع دیگر به‌عمد در کانفیگ اجرایی رد می‌شوند تا به‌اشتباه سالم و ادغام‌شده تلقی نشوند.
