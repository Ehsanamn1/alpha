# وضعیت آلفا — 0.3.0-alpha

## قابلیت‌های پیاده‌سازی‌شده

- هسته Go برای روتر SOCKS5 محلی، پایش سلامت، آزمون HTTP/HTTPS و انتخاب مسیر برای اتصال‌های جدید.
- داشبورد محلی فارسی RTL، نوار موبایل، PWA shell، وضعیت مسیرها و ابزار عیب‌یابی.
- واردسازی لینک‌های share و متن Base64 برای VLESS، VMess، Trojan، SS، Hysteria2، TUIC، AnyTLS، SOCKS و HTTP proxyهای دارای اطلاعات احراز هویت.
- ذخیره‌سازی محلی فهرست کانفیگ‌ها، حذف تکراری‌ها، حذف نود از پنل و عدم بازگشت URI خام حاوی کلید از API فهرست.
- افزودن منابع HTTPS و پیش‌نمایش کانال عمومی تلگرام؛ همگام‌سازی دوره‌ای در حال اجرای پنل محلی.
- تولید کانفیگ sing-box، گروه urltest، بررسی کانفیگ پیش از launch، شروع/توقف دستی و تلاش برای راه‌اندازی مجدد موتور پس از خروج ناگهانی.
- محدودیت حجم ورودی/منبع، اعتبارسنجی URLهای منبع و redirectها، DNS resolution/pinning به IP عمومی هنگام دریافت مستقیم و فایل‌های حساس با مجوز محدود.
- گردش CI/release و buildهای cross-platform در سورس.

## محدودیت‌های تأییدشده

- نسخه روی شبکه واقعی ایران و مسیرهای فیلترشکن عمومی آزمایش میدانی نشده است.
- در این محیط باینری رسمی sing-box نصب نبود؛ بنابراین `sing-box check` واقعی و اتصال به نودهای زنده آزمایش نشده‌اند. parser و تولید JSON با آزمون واحد بررسی می‌شوند.
- دریافت منبع به دسترسی فعلی سیستم به منبع وابسته است؛ اگر تلگرام یا میزبان HTTPS مسدود باشد، دریافت از آن منبع ممکن است شکست بخورد. fetch از مسیر پراکسی فعال هنوز کامل نشده است.
- Google search API/scraping، پروتکل DNS خود TheFeed، iodine و Spoof Tunnel ادغام نشده‌اند.
- نودهای Diban/MasterHttpRelayVPN/Zyrln/LTSC/Psiphon/Xray/Tor در این سورس یا باینری گنجانده نشده‌اند؛ برخی فقط در صورت وجود موتور یا endpoint محلی سازگار قابل استفاده‌اند.
- PWA فقط پنل کنترل است؛ Android `VpnService`، iOS `NetworkExtension` و VPN سیستمی دسکتاپ هنوز کامل نیستند.
- «کانفیگ نامحدود» از نظر مطلق وجود ندارد؛ سقف عملیاتی فعلی ۱۰۰۰ منبع، ۵۰٬۰۰۰ نود و ۸ مگابایت برای هر منبع است.
- اتصال همیشگی تضمین نمی‌شود؛ دسترس‌پذیری اینترنت، سرور، اپراتور، DNS و قوانین موتور بیرونی تعیین‌کننده‌اند.

## معیار ورود به بتا

1. اجرای موفق `sing-box check` روی build رسمی مشخص و کانفیگ‌های واقعی.
2. آزمون end-to-end روی Windows، Linux و macOS.
3. تست source refresh، قطع/وصل و recovery روی شبکه‌ای با اجازهٔ آزمایش.
4. ممیزی امنیتی ورودی‌ها، منابع، ذخیره‌سازی credential و اجرای پروسه.
5. تأیید workflowهای GitHub Actions و ریلیز قابل دانلود؛ آزمون موبایل native جداگانه باقی می‌ماند.
