# نقشه راه Alpha — نسخه 0.4.0-alpha

## تکمیل‌شده در این نسخه

- [x] هسته Go برای روتر SOCKS5 محلی، پایش سلامت و انتخاب مسیر سالم برای اتصال‌های جدید.
- [x] کنسول فارسی RTL با ناوبری موبایل، PWA shell، نمایش مسیرها و گزارش عیب‌یابی.
- [x] واردسازی دستی چند لینک و متن اشتراک Base64 با حذف موارد تکراری.
- [x] پشتیبانی parser برای VLESS، VMess، Trojan، Shadowsocks، Hysteria2، TUIC، AnyTLS، SOCKS و HTTP authenticated.
- [x] ساخت تنظیمات sing-box و `urltest` خودکار، اعتبارسنجی تنظیمات قبل از اجرا و supervisor برای شروع دوباره پس از خروج ناگهانی.
- [x] مخزن محلی کانفیگ‌ها و منابع HTTPS/پیش‌نمایش کانال عمومی تلگرام، با همگام‌سازی دوره‌ای و محدودیت اندازه.
- [x] کنترل توکن جلسه، محدودکردن listener به loopback، محافظت CSP، عدم افشای URIهای دارای credential در API فهرست.
- [x] CI و گردش ساخت باینری/ریلیز برای Windows، Linux و macOS.

## فاز 1 — اتصال‌های واقعی و ایمنی

- [x] افزودن تست انتهابه‌انتها برای دریافت منبع HTTPS از مسیر روتر SOCKS5 آلفا و موتور رسمی sing-box 1.14.2؛ در Linux و Windows با TLS آزمایشی و SOCKS نگاشت‌شده اجرا می‌شود.
- [ ] اجرای پذیرش end-to-end با باینری رسمی sing-box و کانفیگ‌های واقعی روی دستگاه‌های Windows/Linux/macOS.
- [x] CI نمونهٔ هشت پروتکل را مقابل sing-box رسمی v1.14.2 اعتبارسنجی می‌کند؛ گونه‌های اختصاصی سرویس‌دهندگان و اتصال به endpointهای واقعی همچنان به آزمون پذیرش میدانی نیاز دارند.
- [ ] افزودن واردسازی استاندارد Clash YAML / sing-box JSON با schema validation و تبدیل امن؛ نسخه فعلی لینک‌های share و Base64 را پوشش می‌دهد.
- [x] تلاش دوم برای دریافت منبع از مسیر SOCKS5 محلی آلفا در صورت شکست دسترسی مستقیم؛ مقصد HTTPS به IP عمومی pin می‌شود و اعتبارسنجی TLS حفظ می‌گردد.
- [ ] مدل چندمنبعی برای هر نود، حذف نودهای منقضی‌شده و سیاست نگهداری آخرین نسخه سالم هر اشتراک.
- [ ] backoff، circuit breaker و آزمون قطع‌و‌وصل در شبکه واقعی. fallback از تست SOCKS5 شبیه‌سازی‌شده عبور می‌کند؛ آزمون میدانی ISP همچنان لازم است.
- [ ] ممیزی مستقل امنیتی، مدل تهدید و بررسی دقیق اعتبارسنجی DNS و منابع ناشناس.

## فاز 2 — منابع و پروتکل‌های جداگانه

- [ ] ادغام رسمی TheFeed DNS/feed طبق پروتکل پروژه و آزمون با client/server واقعی؛ کانال `@thefeedconfig` صرفاً یک منبع عمومی پیکربندی است و جای پروتکل TheFeed را نمی‌گیرد.
- [ ] بررسی API مجاز برای کشف منابع عمومی؛ scraping جست‌وجوی Google در این نسخه فعال نیست.
- [ ] انتخاب نسخه و ممیزی امنیتی Spoof Tunnel؛ نیازمند آداپتور TUN/IP، احراز هویت و آزمون دوگره‌ای است.
- [ ] بررسی iodine فقط همراه با طراحی TUN/IP و threat model؛ تونل DNS به‌تنهایی full VPN رمزگذاری‌شده نیست.
- [ ] مدیریت اختصاصی چرخه عمر Psiphon، Tor bridge/transports، Xray و سایر موتورهای مستقل.
- [ ] بررسی مجوز، امنیت و نحوه اتصال Diban، MasterHttpRelayVPN، Zyrln و LTSC؛ فقط وجود endpoint سازگار کافی نیست.

## فاز 3 — اپ‌های سیستمی

- [ ] نصب‌کننده و حذف‌کننده واقعی دسکتاپ، autostart اختیاری و به‌روزرسانی امن.
- [ ] برنامه Android بومی مبتنی بر `VpnService` و TUN.
- [ ] برنامه iOS بومی مبتنی بر `NetworkExtension`، entitlement و توزیع رسمی.
- [ ] امضای باینری/بسته‌ها، SBOM و زنجیره انتشار قابل ممیزی.

## معیارهای انتشار پایدار

- [ ] CI سبز از روی مخزن عمومی و انتشار قابل دانلود.
- [ ] تست میدانی روی اپراتورها و دستگاه‌های واقعی با رضایت کاربران، بدون جمع‌آوری داده شخصی غیرضروری.
- [ ] ممیزی مستقل و مستند threat model.
- [ ] مستندات محدودیت‌ها و hash/امضای artifactها.

این فهرست عمداً بخش‌هایی را که هنوز آزمایش نشده‌اند «کامل» اعلام نمی‌کند. هیچ نرم‌افزاری نمی‌تواند در نبود تمام مسیرهای خارجی، صرفاً با کد اینترنت بین‌الملل ایجاد کند.
