# ماتریس موتورهای پیشنهادی

| پروژه | نقش | اتصال مستقیم به نمونه فعلی؟ | کار لازم پیش از ادغام |
|---|---|---|---|
| Diban | کلاینت/پراکسی با رله Apps Script | بله، اگر SOCKS5 محلی در دسترس باشد | ممیزی MITM/CA و امنیت رله؛ تست سهمیه و دسترسی |
| sing-box | موتور پروکسی عمومی | بله، اگر inbound SOCKS5 فعال شود | پیکربندی امن، بررسی مجوز و آزمون پذیرش |
| Xray-core | موتور پروکسی/انتقال | بله، با inbound مناسب | پیکربندی امن و تست end-to-end |
| Psiphon | سامانه ضد سانسور و تونل | فقط اگر کلاینت محلی پراکسی ارائه کند | بررسی چرخه اجرا، تنظیمات و بسته‌بندی پشتیبانی‌شده |
| Zyrln / LTSC | رله‌های مبتنی بر سرویس‌های عمومی | وابسته به رابط محلی هر پروژه | ممیزی کد و آزمایش اینکه رابط محلی پایدار دارند |
| Spoof Tunnel | مسیر انتقال سطح پایین | خیر، نه در وضعیت پیش‌فرض | بررسی نسخه دقیق، گره خارجی، سیاست شبکه، WireGuard و رمزنگاری مستقل |
| iodine | تونل DNS | خیر، مستقیم نیست | آداپتور شبکه/پراکسی جداگانه و ارزیابی سرعت و امنیت |
| TheFeed | فید/پیام‌رسان کم‌حجم | خیر؛ موتور تونل عمومی نیست | به‌عنوان کانال اضطراری جداگانه طراحی شود |
| Tor transports | ضد سانسور | بسته به کلاینت محلی/پراکسی | بررسی دسترس‌پذیری، پل‌ها و مجوزها |
| GoodbyeDPI / zapret | مقابله با برخی روش‌های DPI | خیر؛ ورودی SOCKS5 ارائه نمی‌کنند | فقط ماژول پلتفرمی جداگانه با تست کنترل‌شده |

قابلیت بالقوه یا مستندات یک پروژه، تأیید عملکرد روی شبکه ایران نیست. همه موارد باید با سناریوها و مقصد آزمون تحت کنترل توسعه‌دهنده آزمایش شوند.
