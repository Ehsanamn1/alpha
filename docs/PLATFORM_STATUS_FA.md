# وضعیت پلتفرم‌ها — 0.3.0-alpha

| پلتفرم | آنچه اکنون موجود است | محدودیت واقعی |
|---|---|---|
| Windows x64 | CLI و داشبورد محلی مرورگر؛ ZIP قابل توزیع | installer، امضا، TUN سیستمی و آزمون روی دستگاه مقصد کامل نیست |
| Linux x64 / ARM64 | باینری cross-compile و CLI/dashboard | باید روی توزیع واقعی تست شود؛ TUN سیستمی آماده نیست |
| macOS Intel / Apple Silicon | باینری cross-compile و CLI/dashboard | تست دستگاه واقعی، امضا و notarization انجام نشده |
| Mobile web / PWA | پنل واکنش‌گرا با نوار پایین و PWA shell | فقط پنل کنترل؛ شبکه موبایل را به VPN تبدیل نمی‌کند |
| Android native | هنوز ساخته نشده | به `VpnService`، TUN، مجوزها و اتصال موتور نیاز دارد |
| iOS native | هنوز ساخته نشده | به `NetworkExtension`، entitlement و فرایند توزیع نیاز دارد |

عبارت «پشتیبانی از پلتفرم» در این آلفا به معنی وجود باینری/رابط است، نه اعتبارسنجی محصول نهایی روی هر دستگاه.
